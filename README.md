# Modèle

A polished static e-commerce prototype for a fictional women's handbag boutique.

## Files

- `index.html` — the complete client-facing experience and all page views
- `styles.css` — responsive visual system, product art, and interactions
- `script.js` — catalog filters, product details, local demo cart, checkout modal, and navigation

## Run

Open `index.html` directly in a browser, or publish the repository with GitHub Pages. No package manager, build step, backend, or installation is required.

All products, prices, customer details, imagery, and contact information are fictional. Checkout and contact controls are visual demo interactions only; no payment or WhatsApp message is sent.

## Image note

The handbag photography in this presentation demo is bundled locally from public Unsplash and Pexels image results. Product names and merchandising details remain fictional; verify image licensing and replace the demo assets before any commercial launch.
